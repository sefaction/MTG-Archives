# Reusable scanner layouts

A collection owner can save an observed card outline and printed anchor positions for future document-scanner images. Advanced review offers **Reuse outline for future scans** after a completed recognition attempt supplies a usable calibration. **Remove saved scanner layout** disables it for future uploads. An existing scan retains the layout snapshot taken when its upload began, including after settings change or an upload acknowledgement is retried.

Calibration requires an actual saved manual outline or measured black/white scanner edges, a readable collector anchor and one unambiguous reading direction. Declared whole-image, background-trim, reference-derived and known-clipped outlines cannot train a layout. A claimed manual source also requires the current operator selection. The stored recipe contains source provenance, dimensions, corners and positions; it contains no card names, collector values or expected printing IDs. Save/reset commands repeat the existing batch/owner/source/revision authorization and transactional replay/history rules. Saving a layout does not change the card's review, revision, physical count or Inventory.

The native fallback applies only when a future CARD_SCAN has declared whole-image geometry. A measured edge, manual selection, reference region or known clipping retains precedence. Scanner width must match. A vertical frame difference up to 2% is allowed only with both collector and title anchors; the calibrated card retains its original pixel dimensions rather than stretching with the image height. Translation is limited to 1.5% per axis and anchor disagreement to 0.4% of the frame diagonal. Corners must remain inside observed source pixels. These are bounded compatibility controls, not qualification for every scanner size, frame style, crop or DPI setting.

Successful inference supplies a separate bounded title/footer OCR attempt on the original pixels through the inferred frame. Original geometry, directional text and boxes remain intact. The extra attempt starts only before 20 seconds and keeps the normal parent deadline; evidence-size exhaustion drops the optional layout before previously qualified source-footer evidence. Separate frames and directions resolve independently, retaining conflicts and human-review requirements. Later reference refinement keeps scanner-layout observations rather than discarding their contributions. Review exposes separate inferred readings and an editable suggested outline, omitting source fingerprints. An inferred outline is never a measured physical edge or an automatic printing/Inventory decision.
