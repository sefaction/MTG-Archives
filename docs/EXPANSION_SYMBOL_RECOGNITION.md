# Expansion-symbol observations

Registered scanner images now have an optional expansion-icon observation in the standard type-line window. The detector compares observed dark and light shapes against SHA-pinned bundled Keyrune glyphs. Identical glyphs retain all set aliases. It compares scan and reference independently; selected card metadata never supplies an expected icon label.

This is an advisory inspection cue. Similarity scores are shape distances, not calibrated probabilities. A reprint may retain its original icon, and several products share icons. Symbol observations do not change proposal ranking, exact identifier decisions, stamp policy, manual review, or Inventory acceptance.

Missing alignment, small source images, clipped regions, low contrast, unsupported shapes and close alternatives remain uncertain. Conflicting supported observations across candidate faces are shown as conflicting. Original bytes remain authoritative. Optional evidence is omitted if it exceeds the existing native or application output budget; omission means not checked.

## Development evidence

- Public-reference diagnostic: 300 fronts across 193 catalogue set codes, 46 supported families, 7 ambiguous and 247 unreadable. This is coverage exploration, not scanner accuracy. One apparent catalogue mismatch was visually verified as the printed ATQ anvil on an RIN reprint. Internal details on CMA and BRC had produced false heart matches; complete-mark enclosure checks corrected those cases.
- Actual native scanner diagnostic: four rotations/paddings of one physical SPM card all align with distributed reference landmarks. All four icon observations remain below the conservative 0.90 support threshold. Three rank SPM first; one ranks an unrelated partial shape first. Lowering the threshold for this card would hide that problem and is excluded.
- Two additional complete/clipped scanner controls from another card do not align to the supplied SPM reference and remain unreadable. These are controls, not two more successful SPM observations.
- Raster controls cover whole icons, reversed polarity, multiple competing marks, generic shapes and text. Asset integrity, physical visibility, unchanged legacy evidence and strict output limits have separate guards.

The fixed window covers standard layouts; older, borderless, showcase, double-face and unusual layouts need further coverage. Independent scanner examples with verified physical boundaries and exact printings, including confusing reprints, remain necessary. No 99% recognition claim is established.

## Remaining recognition work

Current techniques include physical edge detection, reference-landmark alignment and optional rereading, orientation-aware title/footer OCR, exact set/collector parsing, public-image proposals, stamp observations and registered local printing comparisons. Remaining work includes wider layout-specific anchors, stronger symbol extraction, calibrated printing discrimination, and a frozen independent scanner benchmark measuring boundaries separately from exact printing identification.
