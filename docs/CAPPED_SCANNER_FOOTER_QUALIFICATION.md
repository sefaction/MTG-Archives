# Capped scanner footer admission

Related to issue #838 and parent trackers #463/#307; delivered by PR #845. This batch repairs only the admission boundary demonstrated by the frozen Island development original. Footer row-pairing geometry, spaced/ambiguous collector interpretation, three unavailable originals, exact historical-generation replay and independent printing accuracy remain outside this repair.

A supported title can have hundreds of cached printings. Previously, that title prevented the whole-photo fallback even when no collector was read and the correct printing fell outside the 12-item display cap. The existing positioned-source footer channel could retrieve the printing when explicitly requested, but normal primary recognition never requested it.

## Behavior

The new scanner-only admission applies when proposals are review-required, truncated, have one selected direction, have a supported noncontradictory title, and contain no parsed collector. It requests the existing whole-photo read. Explicit collector evidence, conflicts, ambiguous directions, uncapped names, ordinary PHOTO input, explicit manual regions and completed calibrated layouts retain their prior admission paths. Existing unknown/fragment-title fallback is unchanged.

The raw recognition key now includes `capped-scanner-footer-v2`; output versions record that policy. Catalog-only changes still do not change raw recognition identity. An old completed raw attempt cannot silently represent this new policy. Historical accepted reviews and raw evidence are not rewritten by this change.

The existing maximum 32-second fallback, 35-second elapsed recognition allowance, 45-second processing deadline, leases, model/native privileges, resources, original storage and manual/Inventory authority remain. Positioned source support remains review-only. No parser, geometry margin, confidence threshold, native OCR model, finish or automatic acceptance rule changes.
