# Public Wishlist browsing

Brian's November25,2026 request replaces the standalone public Wishlist list
with Inventory's shared workspace, table, binder, sizing, column choices,
card detail dialog and paged/infinite browsing. Binder sorting is available
directly in the shared browser, including ordinary Inventory.

Wanted quantities stay separate by category and exact public preference.
Anonymous and signed-in visitors see only categories the route's owner opted
into. Query parameters cannot change the owner or enable another category.
Private notes, deck/partner names, desired condition/language, source IDs and
storage stay excluded; public catalog artwork/rules/printing data enrich rows.
Missing catalog artwork retains the wish with a placeholder.

Sorting is global before paging and uses numeric wanted quantities and the
displayed catalog unit quote. An unrestricted finish shows a starting quote
("From"), not a claim that nonfoil is required. Known finishes use their own
quotes; genuine zero and unknown prices remain distinct. Existing owner-hidden
public pricing is honored in the Wishlist as well as its client payload.

No Wishlist, Inventory, deck, trade or sharing writes occur while browsing.
No schema, dependency, Compose or environment prerequisite is added.
