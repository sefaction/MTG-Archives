# Document-scanner recognition techniques

The target is correct name, set and collector number. Reliable outer-card geometry precedes every targeted region. Development controls do not establish 99% independent accuracy.

| Technique | Current behavior | Remaining work |
| --- | --- | --- |
| Physical framing | Conservative black/white-rim geometry, measured-clipping vetoes and editable manual boundaries. | Fresh independently labelled boundary-location evaluation. |
| Reference landmarks | Distributed SIFT/RANSAC alignments, source-pixel scanner rectangle checks and one bounded targeted reread. Native manual/commit/cancel, recovery and ordinary owner/run load controls are qualified. Original readings remain available. | Wider layout coverage and independently labelled geometry evaluation. |
| Saved scanner layout | Explicit owner-scoped calibration freezes trusted card size, placement and observed title/collector positions for future uploads. Small corroborated offsets can propose an inferred outline; separate saved-placement anchor searches cover larger fixed margins. | Broader layout/rotation coverage and fresh physical-boundary validation. |
| Printed identifiers | Offline PP-OCRv5 English models read oriented title/footer strips. Parsing and catalogue lookup combine name/set/collector/language while retaining contradictions. Original-resolution left-footer evidence is implemented; inferred scanner crops retain an additional source-pixel footer read. | Weak/fragmented identifiers, uncommon layouts and other-language accuracy. |
| Artwork/whole-card matching | Frozen DINOv2 retrieval and local-feature comparisons offer public-reference candidates. | Similar artwork does not prove exact printing; stronger discrimination of shared-art variants. |
| Lower-left stamps | Registered pixel evidence and verified reference annotations distinguish printing expectation from what is visible. Unreadable stays unknown. | Broader qualified templates, visibility coverage and exact-printing evaluation. |
| Printing detail windows | Registered type-line, footer and frame observations; pinned expansion-symbol shape recognition is implemented. Unsupported, partial and conflicting symbols remain uncertain. | Wider symbol/layout extraction. Offline common-frame discrimination has no demonstrated development gain and is not used for ranking. |
| Decision confidence | Versioned observations, source/lease fences, bounded work and separate human review/Inventory authority. | Calibrated exact-printing confidence and frozen independent scanner evaluation. Raw OCR/image similarity is not a probability. |

The requested anchor fallback now uses both matched public-reference landmarks and an explicit reusable scanner layout. Saved placement guides a bounded search when generic image strips miss printed anchors. Current title and collector positions must corroborate the guided result; stored placement alone cannot prove the physical edge or exact printing. Direct measured/manual boundaries and known clipping retain precedence. See [calibration](SCANNER_LAYOUT_CALIBRATION.md), [inferred original-pixel footer](INFERRED_SCANNER_SOURCE_FOOTER.md) and [guided anchor search](SCANNER_LAYOUT_GUIDED_ANCHORS.md) for qualification and limits.

The next accuracy work is an independent, labelled boundary and exact-printing benchmark, wider weak-identifier/layout coverage, and stronger shared-art printing discrimination. The supplied191 JPEGs match retained development data and cannot establish unseen-card accuracy. Candidate-specific registration must preserve distinguishing details, and absent observations cannot count as support.

Finish and condition remain explicit operator choices. Current implementation and acceptance are recorded in [reference refinement](REFERENCE_ANCHOR_REFINEMENT.md), [printing memory](PRINTING_MEMORY.md), [expansion symbols](EXPANSION_SYMBOL_RECOGNITION.md), [source footer](SOURCE_FOOTER_IDENTIFIERS.md), [#463](https://github.com/sefaction/MTG-Archives/issues/463) and [#749](https://github.com/sefaction/MTG-Archives/issues/749).
