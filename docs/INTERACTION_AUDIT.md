## Long-running progress

Import/card-identification progress now reuses persisted `ImportBatch` and `ImportBatchItem` rows. A lightweight progress endpoint calculates actual totals from saved row statuses, and the selected import batch page polls while the job is non-terminal. The progress bar percentage is derived only from processed item counts, never elapsed time.

Some import operations still execute inside server actions rather than a separate worker. During those requests the initiating button shows pending feedback; after a batch exists or the page is reloaded, progress is recovered from the database-backed import rows.
