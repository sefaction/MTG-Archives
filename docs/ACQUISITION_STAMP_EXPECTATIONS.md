# Catalog printing and reference-image stamp evidence

## Decision and boundary

Public image annotations describe the pixels of a comparison image. They are
separate from the stamp expected on a catalog printing. An unannotated image
must not make a detected physical stamp unusable for a known List counterpart.

This interpretation qualifies paper PLST records with a composite source-set
collector identifier. They expect PRESENT. A proposed paper counterpart with the
same name, language and printed source set/collector expects ABSENT. The inference
is bounded to actual native candidates, not all entries in the catalog. Other
treatments remain UNKNOWN unless a verified reference annotation is available.
It does not qualify every Mystery Booster treatment or establish its release.
The shared printed identifiers on stamped reprints follow
[Wizards' description of the original Mystery Booster reprints](https://magic.wizards.com/en/news/announcements/mystery-booster-revealed-2019-11-11).

Catalog expectation never supplies a physical observation. A comparison requires
nonconflicting PRESENT/ABSENT evidence, supported visible footer/corner alignment
and sufficient source width. An unreadable candidate can reuse a native shared
observation only after the same physical outline is independently checked against
the recorded supporting candidate. Clipped corners, missing references, uncertain
alignment and conflicting observations remain unresolved. A failed detector still
does not prove absence. The native detector, registration and thresholds are unchanged.

Agreements reorder only existing printing families. Contradicted alternatives
remain available for correction. Image/text identity remains necessary and
automatic confirmation stays disabled. Advanced review separately shows printing
expectation, its source and reference-image annotation; old saved summaries remain
readable. Simple review uses the resulting stamp comparison when that UI batch is loaded.

## Durable processing version

`catalog-stamp-expectations-v1` is independent of the native model descriptor.
The job key, input and saved output include the interpretation version. Completed
older observations remain immutable. Eligible unreviewed candidates receive a new
job; obsolete pending interpretation jobs become SUPERSEDED before pixel/native IO.
Existing human-review, owner, photo-generation, source-revision and commit fences
remain authoritative. The photo transport still contains only candidate identities
and original bytes, with no ground truth or account metadata.
