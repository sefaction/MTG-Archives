The bounded window is x=24..630 and y=1270..1396 in the existing 1000x1397 oriented card frame. Each direction is handled separately. The extractor projects that window into the original, verifies that it is observed, and caps the resulting image at 1280x512 without upsampling. Known physical clipping, missing geometry, small source pixels and out-of-frame windows produce an explicit unavailable observation. Detected line boxes are restored to the same card coordinates as the other readings.

Existing title/footer and supplemental readings remain separate. New words and conflicts use the recovered-footer-layout review policy. They can help catalogue search but cannot authorize automatic confirmation or Inventory. Original bytes, human decisions and the first machine observations retain their authority.
