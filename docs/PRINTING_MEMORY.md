# Printing worker memory under the existing bound

Issue #753 records a real printing-native SIGKILL at its1GiB cgroup limit during six scanner inputs and four later reference rereads. The eventual successful retries do not establish an uninterrupted reliable run. Registration resolution, feature limits, deadlines, reference-cache bounds and container memory must remain unchanged.

The reference manifest is now decoded with an object hook retaining only printing's required identity, file, digest and optional public preview URL. Names, printing catalogue fields and verified-stat metadata remain in the immutable SHA-verified file; they are not duplicated in the printing process. Card/face identity, reference counts, source-path containment, exact image hashes, stamp annotations and preview image hashes retain their existing checks. Caller metadata is not mutated. Every successful frame also collects released objects and returns unused glibc pages after the image/registration temporaries have left scope. Live reference arrays stay cached under their existing bounds. No pixels or recognition settings are reduced.

31 native printing guards pass, including retained identity/preview values, unavailable optional URL, bounded output, registration/stamp/detail controls and allocator cleanup. Actual cold/warm combined Node/native memory, unchanged observed results and ordinary scanner/browser qualification remain pending. Native generation identity includes the changed worker source. Private images, full traces and snapshots stay local; no independent accuracy or throughput claim is made.
