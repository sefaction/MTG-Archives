## Live anonymous baseline

The cumulative local Docker image before these changes was measured with a headless Chromium page load and rendered dimensions, waiting for the Public inventory heading. Five warm HTTP requests returned 200 in 2,531–2,617 ms after one 4,212 ms first request; response size was 425,311 bytes on this snapshot. At 1366×768, 390×844 and 320×844 CSS pixels, document width matched the viewport. The first result table began at y≈578, 742 and 873 respectively. These are one-device/sample observations, not a p95 benchmark. Anonymous screenshots and measurements live in ignored `test-results/public-audit-*` files. The 320px first attempt captured a streaming skeleton; measurements above waited for the rendered heading.

## Query and test boundary

`getGlobalPublicInventory` pages displayed groups but groups/sorts all matching public rows and fetches all public-owner stacks for visible card IDs. Layout parity will not be claimed to fix that query cost. Existing `browse-pricing-workspaces`, `inventory-workspace`, `league-lifecycle`, public-readonly and policy tests cover representative roles, but no single cross-surface change gate currently checks all shared filter/draft/empty states. Issues #333 and #334 add the implementation and regression contract. Their combined browser run must revisit signed-in Public and League with real rendered dimensions and verify no private row or mutation leaks.
