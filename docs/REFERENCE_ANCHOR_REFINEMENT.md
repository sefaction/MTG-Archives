# Reference-anchor OCR refinement — draft

Continuation of [#744](https://github.com/sefaction/MTG-Archives/issues/744), based directly on unmerged scanner boundary [PR #742](https://github.com/sefaction/MTG-Archives/pull/742) at e8c6826b098ace00490492510e80696706f11e94. Native mechanism, transactional admission/publication, lineage guards and a separately callable OCR handler are implemented. Automatic queue dispatch is disabled; this batch remains draft and #744 is incomplete.

The policy uses actual observed distributed reference alignments, without an expected printing ID, saved human choice or proposal score. Supported in-frame outlines must agree; weak/localized/ambiguous references are rejected. Measured physical clipping vetoes an outline even when the public crop projects inside the clipped original. Direct edge measurements and manual analysis remain authoritative. Already framed scans are skipped across cyclic/reversed corner order.

A separate scanner-only referenceRegion hint preserves original bytes and cannot combine with manual geometry or whole-photo fallback. The native process rechecks actual pixels for measured clipping before warping. Its output explicitly records reference-anchor-region-v1, referenceRegion, primaryGeometry and boundaryVerified=false. It does not claim an operator boundary or a physical edge measurement. Existing bounded title/footer reading strips, two reading directions and automaticAcceptance=false remain.

The versioned lineage input identifies immutable photo/digest/generation, raw model/version, catalog/resolver and reference model, plus all three actual parent IDs/output hashes and supported outlines. The shared pure check rejects stale/cross-scope/mutated/incomplete parents, unknown photo authority, human review/manual analysis, exclusion/commit/cancellation and input/reference mismatch. It recomputes the proposed outline from observed parent evidence and checks catalogue/reference output versions. A stable one-pass key excludes parent refresh IDs, candidate revisions and chosen coordinates.

Admission serializes under the acquisition session lock and locks all three observations before inserting. A partial PostgreSQL unique index on photo ID and lineage key spans revisions; failed and retired attempts consume that admission. Coordinate-bearing input and output use parameterized JSON text to preserve finite numbers exactly. Publication uses one conditional SQL update with the actual database clock, current lease token/input, photo generation/dimensions, ownership/review/receipt authority, exact parent inputs/outputs and newest-parent ordering. An expired lease remains untouched; a live obsolete attempt retires. Original observations stay immutable.

The callable handler checks current parents before and after one request to the existing native stream, passes the original bytes plus the distinct reference hint, and preserves the primary job ID/output hash. Primary and inferred frames resolve independently; their title/footer tokens cannot manufacture cross-frame agreement. Candidate union retains primary contradictions, source reasons and review-only inferred provenance, with unknown finish/condition and the existing 12-visible-proposal cap. It performs no additional whole-photo fallback. The caller must supply the existing processing deadline; ordinary worker dispatch, fairness and downstream catalogue/printing/feedback propagation are still unfinished.
