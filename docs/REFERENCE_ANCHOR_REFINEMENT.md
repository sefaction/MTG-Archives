# Reference-anchor OCR refinement — draft

Continuation of [#744](https://github.com/sefaction/MTG-Archives/issues/744), based directly on unmerged scanner boundary [PR #742](https://github.com/sefaction/MTG-Archives/pull/742) at e8c6826b098ace00490492510e80696706f11e94. Native mechanism and typed lineage guards are implemented. Automatic queue refinement is disabled; this batch remains draft and #744 is incomplete.

The policy uses actual observed distributed reference alignments, without an expected printing ID, saved human choice or proposal score. Supported in-frame outlines must agree; weak/localized/ambiguous references are rejected. Measured physical clipping vetoes an outline even when the public crop projects inside the clipped original. Direct edge measurements and manual analysis remain authoritative. Already framed scans are skipped across cyclic/reversed corner order.

A separate scanner-only referenceRegion hint preserves original bytes and cannot combine with manual geometry or whole-photo fallback. The native process rechecks actual pixels for measured clipping before warping. Its output explicitly records reference-anchor-region-v1, referenceRegion, primaryGeometry and boundaryVerified=false. It does not claim an operator boundary or a physical edge measurement. Existing bounded title/footer reading strips, two reading directions and automaticAcceptance=false remain.

The versioned lineage input identifies immutable photo/digest/generation, raw model/version, catalog/resolver and reference model, plus all three actual parent IDs/output hashes and supported outlines. The shared pure check rejects stale/cross-scope/mutated/incomplete parents, unknown photo authority, human review/manual analysis, exclusion/commit/cancellation and input/reference mismatch. It recomputes the proposed outline from observed parent evidence. A stable one-pass key excludes parent refresh IDs, candidate revisions and chosen coordinates. These functions alone do not establish atomic database authority or durable loop prevention.

Local types and59 targeted TypeScript guards pass;13 model-free native controls pass, including measured clipping on four sides and all four turns. An initial thick-rim fixture did not produce CLIPPED evidence, contrary to its test assumption; this failure is retained. Later controls use the existing actual measured-clipping counterexamples. Unobserved physical clipping remains uncertain.

A read-only SHA-verified retained scan was padded with black margins. Fresh offline visual candidates and printing alignments were computed independently for each quarter turn. All observation digests match their transformed inputs, and the original remains unchanged. This qualifies a mechanism on reused/transformed developer data; reading counts do not establish boundary accuracy, exact first printing or99% independent scanner reliability. Cold isolated visual time includes setup and does not qualify production worker deadlines.

The isolated Docker runs disable network and mount code/models/references/originals read-only. No database, Inventory or shared service is mutated. Current ordinary local Docker remains the qualified740/742/745/747 review; full cumulative application/native load and ordinary-queue desktop/phone review remain pending.
