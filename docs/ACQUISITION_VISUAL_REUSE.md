# Exact reuse of native visual observations

This is a bounded throughput batch under issue463, following the recognition audit's recommendation to reuse unchanged native observations before changing evidence routing. It reuses visual retrieval only. Native algorithms, OCR reading zones, candidate combination, stamp interpretation, queue fairness and explicit Inventory authority retain their existing behavior.

## Identity, storage and publication

New completed visual jobs retain a server-established owner, original byte digest, full native descriptor and declared PHOTO/CARD_SCAN input kind. The descriptor includes the frozen index, encoder, source catalog, reference coverage, geometry/input/retrieval source identities, OpenCV and rotations. One partial indexed exact-key lookup reads at most one retained output; legacy outputs without this envelope, malformed/oversized outputs or inconsistent provenance miss conservatively. No separate pixel or evidence cache is stored. Removing retained history naturally removes reuse opportunities.

The current raw original is read and hash-verified on every hit. Only native evidence is reused: the current photo ID and execution metadata belong to the current job, while catalog reconciliation uses the existing current lineage and policy. Uncertainty, candidate orders and original native inference timing are preserved. `visualExecution` separately reports current handler duration and reuse/request counts. Worker aggregate logs independently count request calls, including attempts that fail or become superseded; a hit alone is not publication authority.

Before and after lookup/inference, the worker verifies the job/input/lease, database-clock expiry, candidate revision/review/exclusion, owner/user activity, session phase, ready/unpurged photo, declared input kind, physical generation and absence of Inventory receipt membership. Atomic visual completion locks the session and rechecks those mutable predicates in the publication statement. Changed input or human decisions save no output; lost/expired leases cannot publish. Native observations remain review-only.
